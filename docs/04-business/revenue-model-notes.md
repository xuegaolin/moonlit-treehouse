## 二、核心假设依据

### 2.1 定价（100% 来自 PRD，未自编）
| 模块 | 付费点 | 定价 |
|------|--------|------|
| A 深夜信箱 | AI 深度回信 / 定制人格 | 4.9 / 9.9 元 |
| B 摆烂许可证 | 高级模板 / 专属定制 / 实体明信片 | 3 / 6.9 / 9.9 元 |
| C 塔罗盲盒 | 三牌阵 / 深度解读 / 情感专题 / 年度报告 | 9.9 / 19.9~68 / 29.9~99 / 99 元 |
| D 许愿池 | 木鱼皮肤 / 结愿仪式 | 6 / 4.9 元 |
| E 漂流墙 | 虚拟礼物 3 档 | 0.6 / 1.9 / 9.9 元 |
| 会员 | 月卡 / 年卡 / 终身卡 | 19 / 128 / 388 元 |

### 2.2 关键假设（可调）
- **模块渗透率**（DAU→模块访客）：摆烂 B 40%（首页主打）＞漂流墙 E 35%（吃瓜围观）＞许愿 D 30%＞信箱 A 25%＞塔罗 C 20%
- **单点付费率**：0.05%~2%（礼物类高、报告类低），整体对标 PRD 的 ≥3% 上限
- **会员转化率**：基准 1.5%（PRD 目标），敏感区间 0.5%~3%
- **月光币抵扣**：10 币=1 元、最高抵 50%——模型中体现为实收 9 折的折损系数

## 三、敏感度分析核心结论 ⭐

### 3.1 最大杠杆排序（基准 DAU 5000 下，月增量流水 Top 5）
| 排名 | 转化路径 | 为什么 |
|------|---------|--------|
| 🥇 | **A → C（信箱→塔罗）** | 深夜 emo 写完信顺手抽牌；C 的 ARPPU（9.9~99 元）全场最高，月增量第一 |
| 🥈 | **D → C（许愿→塔罗）** | 许愿后求"剧透"，玄学闭环；去向同样是高 ARPPU 的 C |
| 🥉 | **B → C（摆烂→塔罗）** | 领完许可证顺手看运势；B 渗透率 40% 全产品最高，来源流量大 |
| 4 | **E → C（漂流墙→塔罗）** | 吃瓜围观后想测测自己；E 渗透率 35% 第二高 |
| 5 | **E → A（漂流墙→信箱）** | 看别人心事引发倾诉欲，回流写信 |

> **结论：塔罗 C 是交叉引流的"收入终点"**——月增量 Top 4 路径（A→C、D→C、B→C、E→C）的去向全部是 C。**所有模块的完成页都应挂塔罗入口；塔罗虽第 2 个月才上线，但它是全产品的变现枢纽。**

### 3.2 二维敏感度（月总收入：交叉转化率 × DAU）
- 交叉转化率每 **+1%**，DAU 5000 时月增收约 **+6,000~9,000 元**
- 对比：DAU 从 1000 提到 5000（5 倍拉新成本），收入 × 5；而交叉转化率从 1% 提到 5%（**零拉新成本，纯产品动线优化**），收入约 × 2.5
- **性价比排序：优化交叉动线 > 提单点付费率 > 拉新**

### 3.3 会员 vs 单点
- 会员转化率 1.5% 时，会员收入约占总收入 **30~40%**（因会员免单点，存在蚕食，模型已按"会员不再单点付费"计算）
- 会员是**收入稳定器**：单点收入随 DAU 波动大，会员是订阅制月复购
- **年卡占比建议做到 40%+**（定价 128=月卡 6.7 个月，用户心理门槛低于 7 个月，留存锁定效果好）

## 四、三条运营建议

1. **把"写信→漂流"做成默认勾选**（A→E 是最大杠杆）。在写信完成页加一行小字"允许匿名公开到漂流墙（可随时撤回）"，默认勾选。仅这一个 UI 决策，按模型测算值 DAU 5000 时约 **+4,000 元/月**。

2. **塔罗结果页加"去许愿"按钮**（C→D、D→C 玄学闭环）。抽完塔罗显示"心愿加持：带着今天的运势许个愿 →"。成本 1 个按钮，双向转化各 +1%。

3. **会员销售时机：第 3 次付费时推**。前两次让用户单点付费（建立"这东西值 X 元"的价格锚点），第 3 次触发付费时弹"你已花 23.7 元，开会员只要 19 元/月全免"。比新用户首日推会员的转化率高 3~5 倍（行业通用数据），模型中对应会员转化率从 0.5% 提到 1.5% 档。

## 五、盈亏平衡（中性情景，DAU 5000）

| 成本项 | 月成本（元） | 说明 |
|--------|------------|------|
| LLM API（回信+解读+理由） | 1,500~3,000 | 按日 2,000 次调用 × 平均 0.05 元 |
| 服务器 + 数据库 | 300~500 | 2C4G + MySQL 云托管 |
| 内容审核 API | 200~400 | UGC 文本审核 |
| 微信支付通道费 | 流水 × 0.6% | — |
| **合计** | **≈2,500~4,500** | — |

> 中性情景（DAU 5000）月收入约 **1.5 万~2.5 万元**（详见 06-汇总看板），**上线后第 2~3 个月可盈亏平衡**（前提是 DAU 爬到 3000+）。
