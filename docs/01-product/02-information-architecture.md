## 二、导航结构

### 2.1 TabBar（底部 4 栏）
| 位置 | 图标 | 标题 | 页面路径 |
|------|------|------|---------|
| 1 | 🏠 | 树屋 | pages/home/home |
| 2 | 📮 | 信箱 | pages/letter/letter |
| 3 | 🔮 | 占卜 | pages/tarot/tarot |
| 4 | 👤 | 我的 | pages/mine/mine |

> **摆烂许可证 / 许愿池 / 漂流墙** 通过首页卡片入口 + 分享回流进入，不占 tabbar

### 2.2 页面层级（最深 3 层）
```
L1 tabbar 页
L2 模块内的详情/操作页（写信/抽牌/生成证书）
L3 完成态/结果页（信件生成成功、塔罗结果详情）
```

## 三、跨模块数据流

### 3.1 月光币流通
```
签到（+10） / 摆烂领证（+5） / 木鱼敲击（+1/次，日上限50）
   ↓
月光币钱包
   ↓
消耗：解锁高级模板 / 塔罗解读折扣 / 兑换周边券
```

### 3.2 交叉引流路径
```
[首页] 用户选"emo"心情
  ├→ 推荐"深夜信箱" → 写完信 → 推荐"塔罗看看未来"
  ├→ 推荐"摆烂许可证" → 领完 → 分享 → 推荐"来漂流墙看看别人"
  └→ 推荐"漂流墙" → 送温暖消耗小额 → 引导"写你自己的心事到信箱"
```

### 3.3 会员权益覆盖
```
19元/月会员 = 全模块特权：
  ✅ 深夜信箱：不限量 AI 回信 + 定制封面
  ✅ 摆烂许可证：全模板解锁
  ✅ 塔罗盲盒：每日免费单张 → 免费三牌
  ✅ 许愿池：全高级木鱼皮肤
  ✅ 漂流墙：置顶投递 + 专属徽章
  ✅ 通用：无广告 + 优先客服 + 月光币 x2
```
