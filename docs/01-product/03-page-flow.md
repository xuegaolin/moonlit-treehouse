## 一、新用户首次进入流程

```
[打开小程序]
    ↓
[启动页 · Logo + Slogan 1.5s]
    ↓
[静默调用 wx.login → 后端换 token → 缓存 openid]
    ↓
[首页 Home]
    ↓
[今日心情选择弹窗（首次）]  ← 可跳过
    ↓
[首页个性化推荐 · 3 张卡片高亮]
    ↓
用户点击任意模块 → 进入对应流程
```

**技术要点**：
- 登录必须静默完成（不能打断用户）
- token 有效期 7 天，过期自动重新走 wx.login
- 首次进入才弹心情选择，之后每天 0 点重置

## 二、模块 A · 深夜信箱 · 写信流程

```
[信箱首页]
    ↓
[点击"我要写信"]
    ↓
[Step 1 · 选收件人]
  ├─ 未来的自己
  ├─ 现在的自己
  ├─ 想念的人（对方看不到，纯宣泄）
  └─ 随机陌生人（会公开到漂流墙）
    ↓
[Step 2 · 选送达时间]
  ├─ 7 天后
  ├─ 30 天后
  ├─ 1 年后
  └─ 自定义（会员）
    ↓
[Step 3 · 写正文]
  ├─ 富文本编辑器
  ├─ 字数：50~2000
  ├─ 可添加信纸背景（免费 3 款 / 付费 8 款）
  └─ 可选"是否要 AI 回信"（免费 1 次/日）
    ↓
[Step 4 · 选 AI 人格（若勾选回信）]
  └─ SISTER / BESTIE / PROF / BUDDHA / STAR
    ↓
[Step 5 · 预览 & 确认]
    ↓
[提交]
  ├─ 免费用户：调用免费额度 或 弹付费
  ├─ 内容安全审核（wx.contentSecurity）
  └─ 生成 letter_id
    ↓
[成功页 · 树屋邮筒动画 3s]
    ↓
[跳转"我的信箱 · 待送达"]
```

**异常处理**：
- 审核失败 → 提示"信件包含敏感内容，请修改后重试"
- AI 回信失败 → 队列重试 3 次 → 客服兜底

## 九、异常/边界流程

### 9.1 未登录/token 过期
```
任何 API 401 → app.js 自动 wx.login → 重试 1 次 → 仍失败弹提示
```

### 9.2 网络异常
```
所有关键接口失败 → 弹 Toast "网络开小差，稍后再试" + 记录到本地
```

### 9.3 内容审核不通过
```
UGC 提交 → 微信安全审核 → 不通过 → 提示模糊"包含不当内容" (不暴露具体规则)
```

### 9.4 支付失败/退款
```
支付失败 → 3 次重试 → 引导切换支付方式
用户申请退款 → 客服模块 → 后台人工审核 → 原路退回
```
