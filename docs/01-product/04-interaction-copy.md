## 一、文案风格

### 1.1 语言基调
- **温柔但不软**：像朋友，不像客服
- **有点小坏**：偶尔毒舌自嘲，避免过分正能量
- **少用感叹号**：句号才是深夜的正确标点
- **拒绝 emoji 泛滥**：一屏最多 3 个 emoji
- **拟人化**：把小程序说成"树屋"、"我"、"她"

### 1.2 高频文案对照表

| 场景 | ❌ 常规 | ✅ 树屋 |
|------|--------|--------|
| 加载中 | "加载中..." | "树屋管理员正在开门..." |
| 网络失败 | "网络异常" | "外面风好大，信号也吹跑了" |
| 空态 | "暂无数据" | "这里还空着，等你写第一行" |
| 提交成功 | "提交成功" | "收到了，放心" |
| 支付成功 | "支付成功" | "叮，月光币入账" |
| 未登录 | "请先登录" | "先让树屋记住你" |
| 内容违规 | "违规内容" | "这些话，树屋没法带你走" |
| 删除确认 | "确定删除?" | "真的要让它消失吗?" |
| 退出登录 | "退出登录" | "先关灯睡觉去吧" |

## 二、5 模块口号与开屏文案

### 2.1 深夜信箱 📮
- **首屏 Slogan**：写一封信，寄给还没到来的自己
- **无信件空态**：邮筒好久没响了。写一封吗?
- **AI 回信开头模板**：
  - SISTER：亲爱的，看到你的信，我想抱抱你...
  - BESTIE：兄弟(姐妹)，我看完了，我先说三句...
  - PROF：你好，我来聊聊我看到的三个关键点。
  - BUDDHA：施主，你说的这件事，其实...
  - STAR：月亮告诉我，你今夜写了这封信。

### 2.2 摆烂许可证 🪑
- **首屏 Slogan**：今天，你有权利什么都不做
- **AI 生成理由样例**：
  - "根据《人间打工人保护法》第 3 章第 8 条，持证人于 2026 年 07 月 25 日经周一综合症确诊，特此授予摆烂权利。"
  - "月光树屋管理委员会认定：该同学今日情绪浓度超过 87%，建议全天摆烂静养。"

### 2.3 塔罗盲盒 🔮
- **首屏 Slogan**：今天的运势，藏在牌背后
- **抽牌前引导**：深呼吸，想着最近困扰你的事
- **免责声明**：塔罗是给心情的镜子，不是命运的答案

### 2.4 许愿池 🕯
- **首屏 Slogan**：把心事投进池子，让月亮帮你听
- **木鱼提示**：功德不催，敲多敲少都是心意
- **结愿祝福模板**："这个夏天你许下的那个愿，最终去了哪里？月光女神为你翻开..."

### 2.5 漂流墙 💌
- **首屏 Slogan**：全世界的深夜心事，都漂到了这里
- **发布引导**：没有评论，只有拥抱
- **送温暖后**：一份小小的暖意，已经送到 TA 那里

## 三、交互细节

### 3.1 动画节奏
| 动画 | 时长 | 曲线 |
|------|------|------|
| 页面切换 | 250ms | ease-out |
| 按钮点击反馈 | 100ms | ease-in-out |
| 抽牌翻转 | 800ms | cubic-bezier(.4,0,.2,1) |
| 木鱼敲击音效 | 200ms | linear |
| 信件投递 | 1500ms | ease-in-out |
| 摆烂证书生成 | 600ms 骨架屏 | shimmer |

### 3.2 反馈原则
- **所有关键操作必须有明确反馈**（震动 / 音效 / 弹窗 / Toast 任选其一）
- **付费类操作必须有二次确认**
- **删除类操作必须可撤销 3s**

### 3.3 引导策略
- 首次进入某模块时才弹引导（cover mask + 3 步走）
- 每个引导可跳过，不打断主流程
- 引导偏好本地存储 `guide_letter_v1: true`

### 3.4 空态设计
- 每个 tab 都有专属空态插画（月亮 / 邮筒 / 塔罗牌 / 木鱼）
- 空态必有一个 CTA 按钮 + 温柔提示语

## 四、无障碍 & 深色模式

### 4.1 深色模式（默认）
> 树屋的定位就是"深夜"，主题以深色为主

- 主背景：`#1a1a2e`（深夜蓝）
- 二级背景：`#16213e`
- 主色：`#6B5CE7`（月光紫，延续 ai-watermark-miniprogram 主题）
- 高亮：`#F5D76E`（月光黄）
- 文字：`#EAEAEA` / `#B0B0B0`（副）

### 4.2 无障碍
- 所有可点击元素 min-size 44×44 rpx
- 关键按钮支持长按 tooltip
- 图片必须有 alt 文案（用于分享截图 alt）

标题：你在 30 天前写的信到了
时间：2026 年 08 月 24 日 22:00
内容：来自过去的自己
备注：树屋等你来拆信

**塔罗盲盒 · 每日提醒（21:00）**
```

副标题：月光女神已翻好牌

```

副标题：编号 ML-20260725-0001

- 每用户每日最多 3 条推送
- 不推送用户已完成的行为
- 深夜 24:00 ~ 08:00 静默期

## 六、错误码 & 用户友好错误

| 错误码 | 场景 | 后端返回 | 用户看到 |
|--------|------|---------|---------|
| 40101 | token 过期 | AUTH_TOKEN_EXPIRED | (静默重登) |
| 40201 | 内容违规 | CONTENT_VIOLATION | 这些话，树屋没法带你走 |
| 40301 | 无权限（未开会员） | NO_PERMISSION | 这个抽屉只有会员能开哦 |
| 40401 | 资源不存在 | RESOURCE_NOT_FOUND | 咦，好像找不到这封信了 |
| 42901 | 请求过频 | TOO_MANY_REQUESTS | 慢一点，我跟不上呢 |
| 50001 | 系统错误 | INTERNAL_ERROR | 树屋停电了，等等再来 |
| 50002 | AI 服务失败 | AI_SERVICE_FAIL | 月光女神在开小差，稍后再问 |

## 七、隐私 & 用户协议关键条款

### 7.1 首次进入必弹
```
《月光树屋用户协议》& 《隐私政策》

我们承诺：
✅ 你的信件内容加密存储，任何人（包括我们）看不到
✅ 匿名 UGC 不会关联到你的微信身份
✅ 内容审核由官方 API 完成，不做人工阅读
✅ 未成年人保护：不满 18 岁请在家长陪伴下使用

我们需要：
· 微信头像 & 昵称（用于个性化证书）
· openid（用于订单和会员身份识别）
· 内容 API 访问权限
```

- 塔罗/许愿池为娱乐性质，不作为决策依据
