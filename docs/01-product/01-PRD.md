## 一、产品概述

### 1.1 产品定位
> **白天你在人间打拼，晚上来树屋躲一躲。**

**今夜树屋**是一款主打 18~30 岁女性用户的**深夜情绪多功能小程序**，采用"情绪超市"策略 —— 在同一个入口下聚合多个情绪解药模块，用户根据当下心情随取随用。

### 1.2 核心价值
- **一站式情绪出口**：难过想倾诉、烦躁想摆烂、迷茫想占卜，全在同一个树屋里
- **不设人设不看脸**：完全匿名、免注册、免登录门槛（微信授权即入）
- **AI 陪伴，成本可控**：核心互动由 AI 驱动，规避真人心理咨询合规风险

### 1.3 竞品差异
| 维度 | 一罐 / 胖鱼 | 电子木鱼 / 塔罗小程序 | **今夜树屋** |
|---|---|---|---|
| 定位 | 单一功能（树洞/倾诉/塔罗） | 单一功能 | 情绪超市 · 多模块 |
| 用户 LTV | 玩腻某功能即流失 | 短平快无留存 | 交叉引流，A→B→C |
| 合规 | 涉及"心理咨询"红线 | 部分涉及玄学争议 | 全 AI + 娱乐化包装 |
| 冷启成本 | 单模块×多次 | 单模块×多次 | 一次投放，多次转化 |

## 二、目标用户

### 2.1 用户画像
- **性别**：女性 70%+ / 男性 30%
- **年龄**：18~30 岁（大学生 + 都市初入职场）
- **活跃时段**：22:00 ~ 02:00（深夜情绪高发期）
- **付费意愿**：中低（9.9~30 元/次为主）
- **心理特征**：情绪浓度高、乐于分享、追求"仪式感"和"小确幸"

### 2.2 典型场景
1. **深夜 emo 女大**：加完班/失恋/被 pua 后打开小程序，先写一封"给未来的信"，再翻一张塔罗牌看运势
2. **周一摆烂族**：周末结束前领一张"周一摆烂许可证"，截图发朋友圈
3. **迷茫大学生**：期末季/毕业季连续多天打卡"每日树洞"，寻求陌生共鸣
4. **许愿党**：考试周/求职季日日许愿、每日签到"月光币"

## 三、产品架构 · 5 大模块

### 3.1 模块 A · 深夜信箱 📮 (Letter Box)
> _给未来的自己写一封信 · AI 帮你回信_

**核心功能**：
- 用户写信 → 选择寄出时间（7天/30天/1年后自动送达）
- 选择"是否要 AI 回信"（AI 扮演不同人格：温柔姐姐/毒舌闺蜜/理性教授/心理咨询师）
- 已寄出/待送达/已收到 三个列表
- 匿名公开信墙（用户可选择"漂流"投递到公共区）

**付费点**：
- AI 深度回信（长版 500 字，含心理分析）：4.9 元/封
- 定制人格（例："爱豆的口吻回信"）：9.9 元/封
- 会员：不限量 AI 回信 + 优先送达 + 定制封面

**技术依赖**：定时任务 + LLM API

---

### 3.2 模块 B · 摆烂许可证 🪑 (Bailan License)
> _今天，你有权利什么都不做_

**核心功能**：
- 每日一键领取"今日摆烂许可证"（PNG 图，含日期+编号+理由）
- 摆烂理由 AI 生成（"根据国务院令第 XX 号..."）
- 分享朋友圈 / 保存图片
- 摆烂日历（累计打卡）
- 摆烂勋章体系（连续 7 天/30 天/100 天）

**付费点**：
- 高级许可证模板（企业风/古风/赛博朋克/宫廷风）：3 元/张 or 会员
- 定制头像 + 姓名的专属证书：6.9 元
- **周边电商**：真实印刷的摆烂许可证明信片 9.9 元（含邮费）

**技术依赖**：Canvas 图片合成 + LLM 生成理由

---

### 3.3 模块 C · 塔罗盲盒 🔮 (Tarot Blindbox)
> _今天的运势，藏在牌背后_

**核心功能**：
- 每日一张免费塔罗 → 抽牌 + AI 解读 + 关键词 3 个
- 三牌阵（过去/现在/未来）：9.9 元
- 情感专题（复合/事业/桃花）：19.9 元
- 塔罗日记：记录每天抽到的牌，形成年度报告

**付费点**：
- 深度解读（含 AI 生成的"专属建议信"）：19.9~68 元
- 情感专题特殊牌阵：29.9~99 元
- **年度塔罗报告**：99 元（生日/元旦推送）
- 会员：不限次免费单张解读

**合规坑**：包装成"娱乐占卜/心理暗示工具"，绝不出现"命理预测"

**技术依赖**：78 张牌图库 + LLM Prompt 工程

---

### 3.4 模块 D · 许愿池 🕯 (Wish Pool)
> _敲一下木鱼，功德 +1_

**核心功能**：
- 电子木鱼（点击音效 + 功德计数）
- 电子上香（选香型：文昌/财运/桃花/健康）
- 许愿池（写心愿 → 扔进池子 → 定期"结愿"复盘）
- 每日签到 + 月光币（跨模块积分）

**付费点**：
- 高级木鱼皮肤（金色/水晶/敦煌壁画）：6 元
- 高级香型（100 元敦煌卷轴香）：会员专享
- 结愿仪式（AI 生成"心愿达成祝福信"）：4.9 元

**技术依赖**：Canvas 动画 + 音效

---

### 3.5 模块 E · 漂流墙 💌 (Bottle Wall)
> _看看别人的深夜心事_

**核心功能**：
- 公开的匿名心事墙（从模块 A 的"漂流"或独立发布）
- 情绪标签：#emo #焦虑 #失恋 #考研 #社畜
- 陌生人可送温暖（抱抱/糖果/烛光）
- 无评论功能（避免网络霸凌）

**付费点**：
- 虚拟礼物：0.6/1.9/9.9 元 3 档
- 会员：置顶投递 + 专属徽章

**合规坑**：需接入内容审核（微信内容安全 API + 自研关键词库）

**技术依赖**：内容审核 + 定时刷屏机制

## 四、非功能需求

### 4.1 性能
- 首页打开 < 1s
- 塔罗抽牌动画流畅（60fps）
- AI 回信响应 < 8s（异步生成，前端显示"AI 正在提笔..."）

### 4.2 合规
- ✅ 类目选择：**生活服务 / 工具**（避开"心理咨询"）
- ✅ 全部 UGC 走内容审核 API
- ✅ 塔罗/许愿包装成"娱乐/心理暗示"
- ❌ 严禁出现："心理治疗""预测未来""命理"字眼

### 4.3 数据存储
- 用户内容加密存储（写信内容）
- 匿名 UGC 与 openid 解耦（用中间 anonymous_id）
